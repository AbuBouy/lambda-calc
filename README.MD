# Pure Lambda Calculus Interpreter

A minimalist interpreter for the pure lambda calculus, supporting variables, abstractions, and applications.

## Features
* **Pure Lambda Calculus**: Supports variables (`x`), abstractions (`λx.M`), and applications (`M N`).
* **Beta Reduction**: Evaluates expressions to their normal form using standard reduction strategies.
* **Lexer & Parser**: Converts raw text strings into abstract syntax trees (ASTs).
